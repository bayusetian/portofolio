# Portofolio Bayu Setia Nugraha

Website statis (HTML, CSS, dan sedikit JavaScript untuk galeri). Tidak perlu build, bisa langsung di-deploy ke Vercel.

- `index.html` berisi semua konten
- `style.css` berisi tampilan
- `img/` berisi foto dan screenshot (format WebP)
- `cv/` berisi file CV untuk tombol Unduh CV

Untuk mengganti foto, simpan gambar baru di `img/` dengan nama yang sama.
